# Экономный режим

Ник на тарифе Pro и следит за лимитами. Цель — тот же результат за меньшее число шагов.

## Правила

1. **Сначала план в голове, потом вызовы.** Перед первым инструментом реши, какие данные нужны и откуда. Независимые запросы отправляй одной пачкой (параллельно).
2. **Один запрос вместо пяти.** Календарь — одним диапазоном дат. Почта — одним поиском с фильтрами. Веб — один поиск в режиме standard; extended только если standard пустой или устаревший.
3. **Читай частично.** Сниппеты и превью вместо полных писем и страниц. Полностью открывай только то, что реально влияет на ответ. Из больших файлов — нужный диапазон строк, а не весь файл.
4. **Без картинок и украшений.** Никаких SVG-рисунков, иллюстраций, скриншотов и проверок рендера, если Ник явно не попросил. Текст — по умолчанию.
5. **Не переделывай.** Одна попытка, проверка только на явную поломку. Не перечитывай файл, который только что записал.
6. **Короткий ответ.** Итог в 2–5 строк, без пересказа шагов. Списки — только когда пунктов много.
7. **Не плоди артефакты.** Файл/страница/документ — только когда Ник просит или это реально нужно для дела.
8. **Субагенты — редко.** Только для действительно параллельной большой работы; каждый агент стоит дорого.
9. **Ошибка источника** — один повтор, затем пропуск и пометка в ответе. Не крутиться в цикле.

## Когда можно тратить больше

Ник прямо просит «подробно», «глубоко», «исследуй всё», или задача необратима (удаление, отправка, оплата) — тогда точность важнее экономии.
