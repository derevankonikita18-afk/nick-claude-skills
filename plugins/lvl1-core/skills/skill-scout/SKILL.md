# Skill Scout — прокачка уровней

Репозиторий Ника `nick-claude-skills` — это маркетплейс плагинов Claude. Каждый плагин = ветка/уровень, внутри — навыки (`skills/<имя>/SKILL.md`). Прогресс ведётся в `LEVELS.md`.

## Процесс

1. **Понять цель.** Какая ветка и какая работа? Если неясно — один короткий вопрос. Сверься с `LEVELS.md`: может, навык уже есть или запланирован.
2. **Поиск (2–3 веб-поиска, не больше).** Где искать в первую очередь:
   - официальные репозитории вендоров (`anthropics/skills`, `n8n-io/skills`, репозитории Supabase, Vercel и т.п.);
   - каталоги: skills.sh, claudemarketplaces.com, списки awesome-claude-skills на GitHub.
   Клонировать кандидатов через `git clone --depth 1` в отдельную пустую папку и читать SKILL.md целиком.
3. **Проверка — каждый пункт обязателен:**
   - Лицензия разрешает копирование (MIT, Apache-2.0, CC-BY). Без лицензии — не копировать, только написать свой навык по мотивам.
   - Безопасность: никаких скриптов, которые отправляют данные наружу, качают и запускают код, просят токены в чат. Любые скрипты прочитать полностью.
   - Польза: конкретные шаги, команды, шаблоны. «Ты эксперт по …» без процедуры — мусор, отбросить.
   - Размер: SKILL.md желательно до ~15 КБ; длинные справочники — в отдельные файлы рядом, на которые SKILL.md ссылается.
4. **Решение:** взять как есть / адаптировать / написать свой. Чаще всего лучше короткий свой навык на русском под задачи Ника + ссылка на источник.
5. **Добавить в репозиторий:**
   - Свой навык → `plugins/<ветка>/skills/<имя-латиницей>/SKILL.md` с frontmatter `name` и `description` (description — что делает и когда срабатывать, с русскими триггер-фразами).
   - Чужой навык → скопировать папку целиком + файл LICENSE + строка источника в `CREDITS.md`.
   - Целый чужой плагин-маркетплейс → не копировать, а добавить ссылку в `.claude-plugin/marketplace.json`: `"source": {"source": "github", "repo": "владелец/репо"}`.
   - Новая ветка → новая папка `plugins/lvlN-<ветка>/` с `.claude-plugin/plugin.json` и запись в `marketplace.json`.
   - Поднять `version` в plugin.json изменённого плагина.
6. **Обновить `LEVELS.md`:** отметить навык ✅, пересчитать уровень, вписать дату.
7. **Доставка.** Если есть доступ к GitHub (Claude Code на Mac с `gh`) — закоммитить и запушить. Если нет — отдать Нику zip или изменённые файлы и одной строкой сказать, куда их загрузить.
8. **Итог Нику (3–5 строк):** что добавлено, откуда, какой теперь уровень, что обновить в Claude (Плагины → маркетплейс → обновить).

## Принципы

- Меньше, но лучше: каждый установленный навык добавляет ~100 токенов описания в каждую сессию. Не ставить навыки «на всякий случай».
- Описание навыка — короткое и точное, иначе он сработает не вовремя.
- Не дублировать встроенные навыки Claude (xlsx, docx, pdf, pptx уже есть).
