# Рабочее пространство Ника

Язык общения — русский. Часовой пояс — Asia/Bangkok (Пхукет, UTC+7). Обращение — «Ник».
Ник только осваивает ИИ: объясняй простыми словами, без жаргона, команды давай готовыми к копированию.

## Проекты (направления)

| Направление | Суть | Где живут данные |
|---|---|---|
| Недвижимость Пхукета | Первичный рынок: систематизация данных застройщиков для агентства и агентов | Google Sheet «База застройщиков Пхукета» |
| Боты | Telegram-бот @Raumer_bot, автоответчик в мессенджерах, бот для базы застройщиков | Код на Mac / VPS |
| Автоматизация | n8n на своём сервере: напоминания, обновление данных, workflow | VPS (план: $5–7/мес) |
| Задачи и сводки | Утренняя/вечерняя сводка, приоритеты главное/второстепенное/третичное | Google Sheet «Задачи Ника» |
| Контент | YouTube @n_raumer (Raumer Drone Views), TikTok; монтаж в CapCut | Mac |
| Идея: сервис аренды | Жильё, авто, байки на Пхукете: сайт + Telegram mini app | — (стадия идеи) |

## Что использовать

- **Таблицы** → коннектор Google Sheets (читать перед записью, писать точными диапазонами).
- **Почта / календарь** → коннекторы Gmail / Google Calendar.
- **Документы для людей** → Claude Docs; файлы Word/Excel — только если Ник просит формат.
- **Код и сервер** → Claude Code на Mac Ника; облачная сессия не видит его Mac, если компьютер не подключён.
- **Свежие факты** (законы, визы, цены, новости) → веб-поиск, всегда со ссылкой на источник.

## Правила

- Секреты (токены ботов, пароли, ключи API) — никогда не вставлять в чат, файлы репозитория и таблицы. Только в `.env` на сервере или в менеджере паролей.
- Перед массовыми изменениями в таблицах — показать план изменений.
- Если навык из этого репозитория устарел (поменялись таблицы, инструменты) — предложить Нику обновить его через навык `skill-scout`.
