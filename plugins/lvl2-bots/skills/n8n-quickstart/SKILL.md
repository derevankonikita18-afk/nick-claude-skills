# n8n — быстрый старт

## n8n или код?

- **n8n**: связать сервисы (Telegram, Gmail, Google Sheets, календарь), расписания, вебхуки, простая логика — быстрее и наглядно для Ника.
- **Код (Python-бот)**: сложный диалог с пользователем, много состояний, нестандартная логика, высокая нагрузка.
- Часто — вместе: бот на aiogram для общения, n8n для фоновых задач.

## Частые схемы для Ника

1. **Сообщение менеджера → База застройщиков**: Telegram Trigger (бот в группе) → AI-узел/Code извлекает проект, юнит, цену, статус → IF уверенно → Google Sheets «Юниты» (update), иначе → «На проверку» (append) → уведомление Нику.
2. **Напоминания**: Schedule Trigger (каждое утро, TZ Asia/Bangkok) → Google Sheets «Задачи Ника» → фильтр по дате/приоритету → Telegram сообщение Нику.
3. **Мониторинг изменений**: Schedule → HTTP Request (страница/прайс застройщика) → сравнить с прошлым значением (Data Table или Sheet) → при изменении уведомить.
4. **Входящая почта**: Gmail Trigger → фильтр (не рассылки) → краткое содержание → Telegram.

## Правила сборки

- Таймзона workflow: Settings → Timezone = Asia/Bangkok.
- Credentials (Telegram, Google, Anthropic) — только через раздел Credentials n8n, никогда не вписывать ключи в узлы/Code.
- Выражения: `{{ $json.field }}` — данные текущего элемента; `{{ $('Имя узла').item.json.field }}` — данные другого узла.
- Каждый workflow: понятное имя, узел ошибок (Error Trigger workflow → Telegram Нику).
- Перед включением — прогон «Execute workflow» на тестовых данных.
- Отдавать Нику workflow как JSON для импорта: в n8n → меню ⋯ → Import from File/URL, или вставить JSON в редактор (Ctrl/Cmd+V).

## Где n8n

Своя установка на VPS — навык `n8n-self-hosting`. Когда n8n заработает и включено Instance-level MCP (Settings → MCP), установить плагин уровня 3 `n8n-skills` — тогда Claude сможет сам создавать и запускать workflow в n8n Ника.
