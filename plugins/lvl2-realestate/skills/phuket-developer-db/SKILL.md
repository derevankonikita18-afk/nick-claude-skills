# База застройщиков Пхукета

Таблица в Google Drive Ника, найти по названию «База застройщиков Пхукета» (коннектор Google Drive → Sheets).
Цель — всегда актуальная таблица, простая для агентов. Ник сохраняет полный контроль: сомнительное не пишем, а кладём «На проверку».

## Листы и ключевые колонки

- **Застройщики**: ID застройщика · Название · Сайт · Контакт менеджера · Чат с менеджерами · Примечания · Дата обновления · Источник
- **Проекты**: ID проекта · ID застройщика · Застройщик · Название проекта · Район · Ссылка на карту · Тип проекта · Срок сдачи · Стадия стройки · Форма собственности · Условия оплаты · Рассрочка после сдачи · Скидки и акции · Гарантия дохода (% / срок / условия) · EIA · Лицензии и документы · Фото · Примечания · Дата обновления · Источник
- **Юниты**: ID юнита · ID проекта · Проект · Застройщик · Район · Срок сдачи · Корпус / номер · Тип · Спален · Площадь, м² · Этаж · Вид · Цена, THB · Цена за м², THB · Цена, USD · Цена за м², USD · Мебель · Статус · Условия оплаты (если отличаются) · Скидка на юнит · Планировка · Примечания · Дата обновления · Источник
- **История**: Дата изменения · ID юнита · Что изменилось · Было · Стало · Источник · Кто внёс
- **На проверку**: Дата · Источник · Исходный текст · Что непонятно · Связанный проект / юнит · Статус · Решение
- **Справочники**: допустимые значения (районы, типы, стадии, Freehold/Leasehold, EIA, тип юнита, вид, мебель, статус юнита) + курс USD.

Заголовки перед работой всё равно перечитай (строка 1) — структура могла измениться.

## Форматы

- ID: застройщик `DEV-001`, проект `PRJ-001`, юнит `PRJ-001-<корпус>-<номер>` (например `PRJ-001-A-1205`).
- Срок сдачи: `2027-Q4`. Дата обновления: `ГГГГ-ММ-ДД`.
- Значения в колонках со справочником — только из «Справочников». Нового значения нет → добавить в «На проверку», а не выдумывать.
- Цена — в THB числом. Колонки «Цена за м²» и «USD» — скорее всего формулы: перед записью проверь, не формула ли там, и не затирай.
- Источник — всегда: «прайс <застройщик> от <дата>», «чат менеджеров <дата>», «сайт» и т.п.

## Процесс обновления

1. **Прочитай** нужные листы (только нужные диапазоны) и найди существующие записи по ID / названию проекта / номеру юнита.
2. **Разбери источник** (PDF, Excel, фото шахматки, текст сообщения) в черновик строк. Неуверенно распознанное (цифры с фото, неоднозначный статус) → «На проверку» с исходным текстом.
3. **Покажи Нику план** коротко: добавить N, изменить M (что именно), на проверку K. Для разовых мелких правок можно сразу писать.
4. **Запиши** точными диапазонами. Новые строки — в конец листа. Не меняй чужие строки и формулы.
5. **История:** каждое изменение цены или статуса юнита → строка в «История» (было/стало/источник, «Кто внёс» = Claude).
6. **Проверь** чтением записанного диапазона и дай итог в 2–3 строки.

## Подсказки

- Сравнение нового прайса со старым: ищи юниты, которые пропали (вероятно, проданы → статус «продан» после подтверждения), подорожали/подешевели, новые.
- Дубликаты проектов с разным написанием (Laguna/Лагуна) — сводить к одному ID, вариант названия в Примечания.
- Никогда не публиковать контакты менеджеров застройщиков наружу (в посты, описания для клиентов).
